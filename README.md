# Magic Clover (네잎클로버 마술용 웹앱)

관객 QR → 사진 1(네잎클로버)이 보임 → 공연자가 폰에서 이름·숫자 입력 → 관객이 다시 열면 사진 2의 파란 배너에 이름과 숫자가 적혀 있음.

## 구성

| 주소 | 용도 |
|---|---|
| `/` | 관객용 페이지 (QR이 가리키는 곳) |
| `/admin` | 공연자용 입력 페이지 (비밀번호 필요) |

- 사진 1(`img1.jpg`): 처음 보이는 사진
- 사진 2(`img2.jpg`): 입력 후 보이는 사진 (배너 윗부분에 이름과 숫자가 올라감)

모든 파일은 폴더 없이 한 곳에 들어 있습니다(폰에서 올리기 쉽게).

## 로컬에서 실행

```bash
ADMIN_KEY=내비밀번호 node server.js
# http://localhost:3000        관객용
# http://localhost:3000/admin  공연자용
```

Node 18 이상이면 되고, 설치할 패키지는 없습니다. `ADMIN_KEY`를 안 주면 기본값 `magic`입니다.

## 공연장에서 쓰려면 (배포)

폰끼리 연결되려면 인터넷에 올려야 합니다. Node 서버를 돌릴 수 있는 곳이면 어디든 됩니다(Render, Railway, Fly.io 등).

1. 이 폴더의 파일들을 GitHub에 올립니다.
2. Render에서 New → Web Service, 빌드 명령은 비우고 시작 명령은 `node server.js`.
3. 환경변수 `ADMIN_KEY`에 비밀번호를 넣습니다.
4. 나온 주소(`https://xxx.onrender.com`)로 QR을 만듭니다.

주의할 점
- Render 무료 플랜은 한동안 접속이 없으면 잠들어서 첫 접속이 느립니다. 공연 직전에 한 번 열어 깨워 두세요.
- 서버가 재시작되면 입력값이 사라질 수 있습니다. 공연 직전에 `/admin`에서 한 번 초기화하고 시작하세요.
- 사진 2는 관객이 처음 열 때 미리 받아 두기 때문에, 나중에 바뀔 때 로딩 없이 바로 전환됩니다.

## 공연 진행 순서

1. 공연 전: `/admin`을 열어 비밀번호를 한 번 입력해 두고(폰에 저장됨), 초기화를 누릅니다.
2. 관객이 QR로 접속 → 사진 1이 보입니다.
3. 관객을 뽑고 숫자(1~45)를 듣습니다.
4. 공연자 폰의 `/admin`에 이름과 숫자를 입력하고 적용을 누릅니다. 입력하는 동안 아래 미리보기로 결과를 볼 수 있습니다.
5. 관객에게 아까 그 사진을 다시 보게 합니다(앱을 다시 열거나 새로고침). 사진 2의 배너에 이름과 숫자가 나타납니다.

관객 화면은 일부러 자동 갱신하지 않습니다. 화면을 보고 있는 중에 갑자기 바뀌면 티가 나기 때문입니다. 리허설할 때만 주소 뒤에 `?live=1`을 붙이면 2초마다 자동으로 갱신됩니다.

## 여러 공연을 따로 쓰기

주소 뒤에 `?r=이름`을 붙이면 공연마다 상태가 분리됩니다. 예: 관객용 `/?r=sat1`, 공연자용 `/admin?r=sat1`. QR은 `?r=` 붙은 주소로 만드세요.

## 배너 글씨 위치 조정

`stage.js` 맨 위의 `BANNER` 값(사진 전체 대비 %)을 고치면 됩니다. 글자 색과 크기는 `stage.css`의 `.bt-name`, `.bt-num` 등에서 바꿉니다.

## 사진 교체

같은 이름(`img1.jpg`, `img2.jpg`)으로 덮어쓰세요. 다른 구도의 사진이면 `BANNER` 위치를 다시 맞춰야 합니다.
